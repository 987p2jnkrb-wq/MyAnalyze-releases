# MyAnalyze

MyAnalyze is a Windows desktop app I built to keep everyday finances clear. It brings accounts, completed transactions, upcoming payments, goals and analysis into one place. Your data stays on your computer.

**Current version: 4.2.0** - [Release notes and installer](https://github.com/987p2jnkrb-wq/MyAnalyze-releases/releases/tag/v4.2.0) - [All releases](https://github.com/987p2jnkrb-wq/MyAnalyze-releases/releases)

> This is an independent portfolio project. The source code is maintained in a private repository. This public repository contains releases and a visual overview.

![MyAnalyze dashboard in light mode](https://raw.githubusercontent.com/987p2jnkrb-wq/MDQuality/main/public/images/myanalyze/project/dashboard-light.png)

## What you can do

- Keep track of accounts, income, expenses, loans, liabilities and savings goals.
- Import CSV and PDF statements, review matches and correct transactions before saving.
- Compare months, inspect trends and follow the transactions behind each result.
- Plan upcoming payments separately from completed transactions and account balances.
- Create your own KPIs, review spending alerts and explore scenarios.
- Attach documents, make a full backup and use the app in Polish or English.

MyAnalyze is a personal project, built for practical use rather than bank integration. Imported statements do not silently change account balances.

## Current version: 4.2.0

MyAnalyze 4.2.0 refines the financial workspace across desktop and mobile browser views:

- More consistent dashboards, transaction grids, navigation and financial summaries.
- More resilient CSV/PDF import review, optional starter labels and editable transaction classification.
- Clearer monthly KPIs, financial history and historical NBP exchange-rate information for EUR/USD accounts.
- Better Polish/English localization and presentation of banking products, investments and retirement savings.
- PPK support alongside IKE and IKZE retirement savings.

## Mobile browser views

Introduced in version 4.0, the responsive mobile browser interface includes compact transaction history, configurable shortcuts, swipeable KPIs and spending alerts.

The mobile interface uses a privately shared instance of the app. The Windows download remains the desktop installer; financial data is not uploaded to a public service.

## Inside the app

### A dashboard that shows what matters now

The opening screen brings together available funds, selected KPIs, the current pay period and goals.

![MyAnalyze dashboard in dark mode with amounts hidden](https://raw.githubusercontent.com/987p2jnkrb-wq/MDQuality/main/public/images/myanalyze/project/dashboard-dark.png)

### Changes over time

Month comparisons and trends make it easier to see what changed in income, spending and the result. The current, incomplete month is marked as such.

![Trends and alerts](https://raw.githubusercontent.com/987p2jnkrb-wq/MDQuality/main/public/images/myanalyze/project/trends.png)

### KPIs you can adjust

Indicators have their own view. You can add or edit them and open the transactions behind their values.

![KPI view](https://raw.githubusercontent.com/987p2jnkrb-wq/MDQuality/main/public/images/myanalyze/project/kpi.png)

## Install

Open the [latest published release](https://github.com/987p2jnkrb-wq/MyAnalyze-releases/releases/latest) and download the Windows x64 installer once it has been uploaded.

Before upgrading an existing installation, make a full backup and keep it private: it may contain financial records and personal documents. Verify the installer against the SHA-256 checksum published with its release.
