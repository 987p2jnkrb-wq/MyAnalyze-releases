# MyAnalyze 4.0

## Polski

Wersja 4.0 wprowadza mobilny interfejs MyAnalyze oraz kompaktowy przegląd transakcji.

- Historia konta: grupowanie operacji według dni, statusy anulowanych i odrzuconych transakcji, wyszukiwanie oraz filtry miesięcy.
- Mobilna strona startowa: dostępne środki, przewijane karty KPI i pojedynczo wybierane sygnały wydatków.
- Konfigurowalne skróty do zakładek Managera Finansów z wyborem kolejności i przeciąganiem po przytrzymaniu.
- Uproszczony podgląd importu CSV/PDF, czytelniejsze statusy i objaśnienia dostępne na żądanie.
- Płynniejsze okna, menu i gesty, układ kalendarza dopasowany do telefonu oraz obsługa ograniczonego ruchu.
- Polski i angielski interfejs oraz dokumentacja offline w instalatorze.

Widok mobilny działa w przeglądarce przy skonfigurowanym prywatnym dostępie do własnej instancji aplikacji. Import wyciągu nadal nie zmienia automatycznie salda konta.

**Pobieranie:** `MyAnalyze.Setup.4.0.0.exe` - Windows x64. Plik `SHA256SUMS.txt` zawiera sumy kontrolne. Instalator nie ma podpisu cyfrowego.

## English

Version 4.0 introduces the MyAnalyze mobile interface and a compact transaction overview.

- Account history: transactions grouped by day, cancelled and rejected statuses, search and month filters.
- Mobile dashboard: available funds, swipeable KPI cards and individually selectable spending signals.
- Configurable Finance Manager shortcuts with saved ordering and hold-to-drag interactions.
- A simpler CSV/PDF import preview, clearer statuses and explanations available on demand.
- Smoother dialogs, menus and gestures, a calendar that fits mobile screens and reduced-motion support.
- Polish and English interface and offline documentation bundled with the installer.

Mobile views run in a browser through privately configured access to your own app instance. Statement imports still do not change account balances automatically.

**Download:** `MyAnalyze.Setup.4.0.0.exe` - Windows x64. Checksums are provided in `SHA256SUMS.txt`. The installer is unsigned.
