# MyAnalyze 3.0

This release makes MyAnalyze easier to start using and more consistent day to day.

- A guided first run takes you from your first account to a completed transaction and the dashboard.
- Transaction lists have clearer review, history and editing. Related field changes are saved together.
- Imported statements can be added to inactive accounts, which helps with historical records. Imports still do not change account balances automatically.
- The dashboard, KPI and trend views have been refined in light and dark mode.
- Financial integrity checks help flag items that need review without changing data automatically.
- Polish and English documentation is bundled with the installer and opens from the app.

**Download:** `MyAnalyze Setup 3.0.exe` (Windows x64). The accompanying `.sha256` file contains its SHA-256 checksum.

Before upgrading, make a full backup from the application and keep it private. Version [2.0.0](https://github.com/987p2jnkrb-wq/MyAnalyze-releases/releases/tag/v2.0.0) remains available.
